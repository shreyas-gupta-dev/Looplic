   - Value: Don't use a value (or assign estimated average lead value).
   - Count: `One` (per click/user).
   - Conversion Window: 30 days click-through, 3 days view-through.
2. **Attribution Model**: Data-driven (or Time decay for high-urgency services).
3. **Primary vs. Secondary**:
   - `generate_lead` (Form submit): **Primary** conversion action.
   - `contact_phone_click` (Phone call click): **Primary** conversion action.
   - `contact_whatsapp_click` (WhatsApp chat click): **Secondary** conversion action (observe first, promote once volume stabilizes).
